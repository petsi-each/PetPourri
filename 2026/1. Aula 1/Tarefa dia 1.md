### 1️⃣ Criação do README para o seu perfil do GitHub
Essa etapa consiste em criar um README personalizado para o seu perfil do GitHub, apresentando quem você é, suas habilidades e interesses.

#### O que é um README de perfil?
O README de perfil é um arquivo de markdown que aparece na página inicial do seu perfil no GitHub. Ele funciona como uma introdução ao seu perfil na plataforma. 

#### Passo a passo
1. Acesse o GitHub
2. Clique em new repository
3. Coloque o nome desse repositório **exatamente igual** ao seu nome de usuário
4. Deixe a visibilidade do repositório **pública**    
5. Marque a opção Add README
6. Clique em Create repository
7. Clique no arquivo README.md
8. Edite o arquivo, clicando no ícone de lápis, e adicione as informações que desejar
   * Não esqueça de usar a sintaxe de markdown para adicionar títulos, listas, links ou imagens
   * Coloque o que considerar relevante para um novo usuário que esteja visitando o seu perfil
9. Por fim clique em Commit changes
10. Visite o seu perfil e veja o resultado!

| Elemento           | Sintaxe Markdown                     | Exemplo Renderizado        |
|-------------------|-------------------------------------|----------------------------|
| Título            | # Título                            | <h1>Título</h1>            |
| Subtítulo         | ## Subtítulo                        | <h2>Subtítulo</h2>         |
| Negrito           | \*\*texto**                           | **texto**                  |
| Itálico           | \*texto*                             | *texto*                    |
| Tachado           | \~\~texto~~                           | ~~texto~~                  |
| Lista não ordenada| \- item                              | • item                     |
| Lista ordenada    | 1. item                             | 1. item                    |
| Link              | \[texto]\(url)                        | texto clicável             |
| Imagem            | \![alt]\(url)                         | imagem                     |
| Código inline     | \`código`                            | código                     |
| Bloco de código   | \```linguagem ... ```                | bloco formatado            |
| Citação           | \> texto                             | texto em citação           |
| Linha horizontal  | ---                                 | linha divisória            |

### 2️⃣ Criação e Manuseio de um Repositório
Nessa etapa, você deve:

1. **Criar** um repositório **público** no seu perfil do GitHub com um README
2. **Abrir** uma nova ramificação (`branch` secundária).
3. **Realizar** uma alteração qualquer no README nessa nova branch.
4. **Unir** as modificações (`merge`) com a branch principal.
5. Prontinho!
